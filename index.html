Project Overview

Cryptocurrencies exhibit high volatility, non-linearity, and noisy patterns that make forecasting difficult. This project proposes a hybrid ensemble model that leverages the strengths of ARIMA, LSTM, and XGBoost to improve one-step-ahead price prediction performance.

Problem Statement

Traditional time-series models struggle with the complex, non-stationary nature of cryptocurrency markets. Pure deep learning models, while flexible, may overfit or ignore linear structures. The goal is to design a hybrid ensemble that can capture both linear and non-linear dependencies in crypto price series.

Objectives

  • Model the linear component of price series using ARIMA.
  • Capture complex non-linear and long-term patterns using LSTM.
  • Use XGBoost on engineered features and residuals to refine predictions.
  • Combine model outputs into a unified ensemble forecast.
  • Evaluate and compare ensemble performance against individual models.

Methodology

The hybrid framework consists of three base learners—ARIMA, LSTM, and XGBoost—followed by an ensemble layer that combines their predictions to produce a final forecast.

ARIMA Component

The ARIMA model captures the linear structure and potential seasonality in the cryptocurrency closing price series. After differencing to achieve stationarity, optimal (p, d, q) parameters are selected using information criteria, and residual diagnostics are performed to validate the model.

LSTM Component

The LSTM network is trained on sliding windows of historical prices to learn non-linear temporal dependencies. The architecture typically includes one or more LSTM layers followed by dense layers, optimized using mean squared error loss and early stopping to prevent overfitting.

XGBoost Component

XGBoost is trained on a feature set derived from technical indicators (moving averages, returns, volatility, etc.) and, optionally, on residuals from the ARIMA and LSTM models. It learns complex feature interactions and serves as a powerful correction layer that reduces remaining forecast errors.

Ensemble Strategy

The final prediction is obtained by combining the individual model forecasts. In this project, a simple weighted average is used as the ensemble mechanism: 

Forecast = 0.1 · ARIMA + 0.4 · LSTM + 0.5 · XGBoost

The weights are tuned on validation data to minimize forecasting error metrics such as RMSE and MAPE.
